# Dependencias de ejecución del pipeline de ventas.
#
# Las versiones están fijadas para que cualquiera que clone el repositorio obtenga exactamente el mismo comportamiento.
#
# Todas ellas coinciden con el archivo de restricciones oficial de Apache Airflow 2.10.5 para Python 3.12, y esa alineación es deliberada.
# Puesto que el pipeline corre dentro del contenedor de Airflow, fijar acá una versión distinta de pandas o de pyarrow haría fallar la construcción de la imagen con un conflicto de dependencias imposible de resolver sin renunciar a una de las dos.
# En consecuencia, al mantener un único conjunto de versiones, lo que se prueba en local es exactamente lo que corre en producción.
#
# Referencia
#   https://raw.githubusercontent.com/apache/airflow/constraints-2.10.5/constraints-3.12.txt
